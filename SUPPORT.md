# Support

Need help with LocalSend?

1. **Documentation** — start with the [README](README.md) and the
   [upstream wiki](https://github.com/localsend/localsend/wiki).
2. **HarmonyOS port** — see [docs/HARMONYOS.md](docs/HARMONYOS.md) for build,
   packaging and known limitations of the OHOS version.
3. **Questions** — open a [Discussion](https://github.com/localsend/localsend/discussions)
   on upstream or an issue here if it is fork-specific.
4. **Bugs** — first check whether the bug exists in upstream
   (https://github.com/localsend/localsend). Upstream bugs belong upstream;
   report fork-specific bugs via [issues](https://github.com/nicholyx/localsend/issues/new/choose).
5. **Security** — do not open a public issue; see [SECURITY.md](SECURITY.md).
